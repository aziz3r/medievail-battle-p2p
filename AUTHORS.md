# Auteurs et contributeurs

**MedievAIl Battle — Infrastructure répartie** est une œuvre collective réalisée dans le
cadre du projet réseaux de la formation STI3A à l'INSA Centre-Val de Loire
(octobre 2025 – avril 2026). Le projet prolonge la base de jeu développée pour le projet
Python / POO : les deux dépôts partagent donc une partie de leur historique Git.

Chaque contributeur conserve l'intégralité de ses droits sur ses propres contributions.
L'historique Git complet est préservé dans ce dépôt : la paternité de chaque commit
(auteur, adresse e-mail, date) est celle d'origine et peut être vérifiée avec
`git log --format='%an <%ae> %ad'`.

## À propos de ce dépôt

Dépôt de référence du projet :
[YOUSSEF4315/STI3A-Projet_reseaux_1](https://github.com/YOUSSEF4315/STI3A-Projet_reseaux_1).
Projet de jeu associé :
[awa-b/python-project-2025-2026](https://github.com/awa-b/python-project-2025-2026).

Ce dépôt en est un miroir maintenu par [@aziz3r](https://github.com/aziz3r) à des fins
de portfolio. Il n'a fait l'objet d'aucune réécriture de paternité : seuls les fichiers
générés à l'exécution (environnement virtuel `venv/`, caches `__pycache__/`, fichiers
d'état `battle_*.txt`) ont été retirés de l'historique afin de réduire le dépôt de 32 Mo
à 10 Mo. Le code, les ressources graphiques, les auteurs, les dates et les messages de
commit sont inchangés.

Aucune licence n'a été définie par l'équipe : tous droits réservés aux contributeurs
ci-dessus. Pour toute réutilisation, merci de les contacter.
